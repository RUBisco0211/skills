# Web Demo 视频讲解与操作编排稿

> 目标受众：填写实际受众  
> 目标时长：填写分钟数  
> 建议画面：1920×1080，仅浏览器页面视口  
> 项目说明：明确 Demo、Mock 数据和生产能力的边界

## 录制前准备

1. 写明安装依赖与启动命令。
2. 写明首页、登录态、测试数据和可重复恢复的初始状态。
3. 写明不可点击的占位按钮、会改变数据的操作和需要等待的异步任务。
4. 收起会遮挡业务界面的面板；保持浏览器缩放比例稳定。

**画面操作**

- 停留在首页，展示项目名称和核心指标。
- 鼠标依次指向需要介绍的区域，不急于点击。

**旁白**

在这里填写自然、完整、可直接朗读的旁白。先说明项目解决的问题、目标用户和这段视频将展示的核心流程。

**段后停顿**：4 秒

## 00:30—01:20　核心流程一

**画面操作**

- 点击实际功能入口。
- 等待页面稳定后展示关键控件。
- 在旁白提到结果时再切换到结果区域。

**旁白**

在这里填写与画面操作逐句对应的旁白。说明用户输入、系统处理、输出结果及其价值。段落字数应与可用朗读时间匹配，避免后期极端加速或放慢。

**段后停顿**：4 秒

## 录制与剪辑提示

- 默认两段旁白之间保留 3～5 秒；耗时较长的操作必须用“段后停顿”显式说明原因和时长。
- 页面跳转后先停稳再讲解，鼠标移动平缓，避免无意义来回移动。
- 结尾至少保留 2～3 秒稳定画面。
- 列出可删除的可选片段，便于压缩时长。
